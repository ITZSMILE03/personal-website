## Quick Hosting
1. Unzip this folder.
2. Upload the folder to Netlify Drop, Cloudflare Pages, or Vercel (or any static web host / cPanel `public_html`).
3. Connect your custom domain in your hosting dashboard and update your domain's DNS records as instructed.
